# Repository Security Baseline ## Main Branch Standards - Default branch: `main`. - Protected branch policy (configure on remote): - Require pull request before merge. - Require status checks (`CI`, `Security`) to pass. - Require linear history. - Block force pushes and branch deletion. ## Privacy Controls - Never commit secrets or credentials. - The Tauri host must not start unless `RUNICIPAL_TOKEN_SECRET` is configured with at least 32 bytes; GTK-free repository scans enforce the same gate before token verification. - `.env*`, keys, certs, and runtime databases are ignored by default. - Secret scanning enabled in CI. ## Verification Controls - Mandatory CI checks: format, clippy, tests. - Scheduled security scans with CodeQL. - Dependency updates via Dependabot. - Open Dependabot alerts are tracked as release blockers until remediated or explicitly accepted. - Dependency audit exceptions are tracked in `docs/roadmap/security-advisory-exceptions.json`. - `scripts/dependency-floor-proof.sh` records the current GTK/glib dependency floor. - `scripts/check-security-advisory-exceptions.py` fails when an exception review date is overdue; required CI job `security-exception-governance` enforces current dates through the aggregate `test` gate.
