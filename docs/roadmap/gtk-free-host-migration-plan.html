# GTK-Free Host Migration Plan ## Current execution status — 2026-10-05 The native shell and shared Rust crates are implemented. The Tauri bootstrap, runtime/build dependencies, and installer configuration are removed from the supported workspace. On PR #112 source head `ff367c4`, Linux/macOS/Windows package and URL lifecycle checks, Linux visible notification delivery, and the all-target native dependency guard passed. This completes BI-051's dependency floor exit gate on that source head; any newer PR head must pass its required hosted checks before readiness. BI-049 and BI-050 remain open for unresolved parity work, including interactive tray-menu delivery and macOS foreground activation. ## Objective Retire the GTK/GLib-backed desktop host path without losing desktop parity. The long-term target is a GTK-free native desktop shell with the same user-visible behavior, backed by host-agnostic Rust core logic. ## Execution Model - Use TDD for every phase: write the failing test or contract first, implement the smallest change needed to pass, then refactor only after green. - Use parallel agents for independent workstreams: - one agent maintains backlog and bead tracker consistency, - one agent writes and runs focused tests, - one agent keeps host and security docs synchronized. - Keep host adapters thin and keep user-visible behavior stable while the host implementation changes. - Treat browser-sidecar only as a scoped fallback for parity gaps, not as the default architecture. - Temporary Tauri was the historical comparison path recorded by BI-047. It has been retired from the supported workspace on the current remediation worktree; hosted native validation remains the exit gate. ## Phase Plan | Phase | Goal | Backlog / Beads | Test-first gate | Exit criteria | |---|---|---|---|---| | Phase 0 | Parity evaluation and host decision | `F-047`, `BI-047` | Desktop parity matrix tests and host-decision coverage fail until the required surface is classified. | Parity matrix signed off, must-have/should-have/can-defer split recorded, `BI-047` is complete, and the host path is either native desktop, a documented browser-sidecar fallback, or an explicitly time-boxed temporary Tauri stopgap. | | Phase 1 | Core extraction | `F-048`, `BI-048` | Core contract tests fail until risk scoring, triage, verifier, budget guard, release baseline, and auth-sensitive flows are host-agnostic. | Domain behavior lives in `rocinante-core` with no GUI/runtime dependency and host adapters stay thin. | | Phase 2 | GTK-free native desktop MVP | `F-049`, `BI-049` | Native shell integration tests fail until windowing, menus, dialogs, tray, deep links, persistence, and shortcuts work without GTK/GLib. | The native shell runs the current UI and backend flows on supported desktop platforms without Tauri/GTK/GLib. | | Phase 3 | Parity closure and fallback containment | `F-050`, `BI-050` | End-to-end desktop tests fail until remaining parity items are either implemented or explicitly deferred. | The parity matrix is green or has an approved defer list, and any browser-sidecar fallback is isolated to documented exceptions. | | Phase 4 | Remove Tauri/GTK/GLib | `F-051`, `BI-051` | Dependency-tree tests fail until `gtk` and `glib` are absent from the release graph. | Old host path removed, release docs no longer claim temporary GTK/GLib exceptions, and release gates require zero GTK/GLib transitive dependencies. | ## Phase Details ### Phase 0: Parity Evaluation and Host Decision -
